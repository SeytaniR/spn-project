# Changelogs

## [v0.1.0] - 2026-09-09
### Added
- Setup inicial do projeto React com Vite.
- Configuração do `i18next` para internacionalização (EN, PT-BR).
- Criação dos arquivos JSON simulando a base de dados em `src/data/`:
  - `characters.json`: Órfãos iniciais.
  - `items.json`: Armas, Kits e Relíquias.
  - `monsters.json`: Inimigos e Bosses.
  - `cases.json`: Exemplos de missões procedurais.
  - `traits.json`: Habilidades, Cicatrizes e Maldições.
  - `allies.json`: NPCs aliados e recompensas.
  - `clues.json`: Pistas para fase de dedução.
- Criação do documento `agents.md` com diretrizes para desenvolvimento AI.
- Setup da arquitetura de estilos Mobile-First e orientada a componentes fluidos.
